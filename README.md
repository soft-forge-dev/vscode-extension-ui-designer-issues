## Design with your code

Create and edit `.design` files in your workspace. Your designs are stored locally in a readable, Git-friendly format, so you can version, review, and collaborate on them alongside your code.

- **Design:** Work with pages, frames, shapes, vector tools, text, auto layout, and grids.
- **Reuse:** Build components and variants, and organize shared styles, variables, and libraries.
- **Prototype and hand off:** Connect interactive flows, inspect design details, and generate code.
- **Automate:** Use the `ud` command-line interface to drive editor commands from scripts and AI agents.

See the [product website](https://soft-forge.dev/vscode-extension-ui-designer/) for screenshots, the feature tour, installation instructions, and full documentation.

## Install

Install **UI Designer** from the [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=SoftForge.softforge-ui-designer), or run this command in VS Code:

```text
ext install SoftForge.softforge-ui-designer
```

## Feedback and bug reports

This repository is the public place to report issues and share feedback about the extension.

1. [Search existing issues](https://github.com/soft-forge-dev/vscode-extension-ui-designer-issues/issues) to see whether the issue has already been reported.
2. [Open a new issue](https://github.com/soft-forge-dev/vscode-extension-ui-designer-issues/issues/new) with a clear description, steps to reproduce, expected and actual behavior, and your extension, VS Code, and operating system versions.
3. Add screenshots or a short recording when they help explain a visual issue.

Please don't post passwords, access tokens, personal information, proprietary code, or details of a suspected security vulnerability in a public issue. For security-sensitive reports, use the contact method provided on the [product website](https://soft-forge.dev/vscode-extension-ui-designer/).
