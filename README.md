# UI Designer for VS Code — public issue tracker

This repository is the public bug-reporting and feedback channel for the
[UI Designer extension for VS Code](https://soft-forge.dev/vscode-extension-ui-designer/).
It hosts consumer reports, not the extension's source code.

## Report a bug

1. [Search existing issues](https://github.com/soft-forge-dev/vscode-extension-ui-designer-issues/issues?q=is%3Aissue)
   (including closed issues) to see whether the problem has already been reported.
   If it has, add any new reproduction details to that issue instead of opening a duplicate.
2. [Open a bug report](https://github.com/soft-forge-dev/vscode-extension-ui-designer-issues/issues/new?template=bug_report.yml).
   Include the extension and VS Code versions, operating system, steps to reproduce,
   and expected versus actual behavior. Report one problem per issue.
3. Follow the issue for maintainer questions, workarounds, and resolution updates.
   Reports help prioritize fixes; response and fix times are not guaranteed.

## Feedback and complaints

For feedback or complaints that are not bugs,
[open a general issue](https://github.com/soft-forge-dev/vscode-extension-ui-designer-issues/issues/new).
Explain the problem, its impact, and the improvement you would like to see.
Keep discussion respectful and focused on the extension.

## Before posting

All issues, comments, and attachments are public. Remove passwords, API keys,
tokens, personal information, and proprietary code from reports, logs, and screenshots.
Use a minimal, sanitized example whenever possible. Do not post security
vulnerabilities or exploit details in public issues; use GitHub's private
vulnerability reporting option in the Security tab if it is available.
